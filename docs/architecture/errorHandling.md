# 错误处理与降级

Programmer error 是代码缺陷，operational error 是超时/服务不可用，user error 是可修正输入或状态。不同类别决定记录、重试、提示和恢复方式。

请求层规范化协议错误，组件边界隔离局部渲染，路由边界保护页面，全局边界只兜底未预期失败。不要把所有异常吞掉并返回空数据。

重试仅处理临时且安全的失败；fallback 可用缓存、只读模式或部分内容。错误提示说明发生什么、用户能做什么和数据是否保存，保留可用于支持的 request ID。

局部故障不应拖垮整个页面。恢复后重新校验数据一致性，并把原始 cause、版本与上下文上报监控。
