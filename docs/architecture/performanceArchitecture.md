# 性能架构

性能预算按页面定义关键 JS/CSS、主线程时间和 LCP/INP/CLS 目标，并进入 PR/发布监控。架构评审必须说明新增依赖和运行时成本。

Route 是常见代码/数据加载边界；组件级拆分用于低频重能力；数据预取根据导航概率。避免 JS chunk、接口和子组件形成串行瀑布。

内容页可 SSR/SSG，重交互后台可 CSR/混合，按页面而非全站选择。大列表用虚拟化，大表单缩小订阅，大屏把计算、数据聚合和绘制分离，必要时 Worker/Canvas。

第三方延迟/按需加载，设置预算和故障隔离。所有决策用 RUM 和 trace 复验，不能只靠 bundle size 推断体验。
