# 迁移与遗留系统治理

Strangler pattern 让新实现逐步接管路由/功能，旧系统继续运行。先建立行为测试、监控和基线，再选择边界清晰、收益高的切片。

Adapter 让新代码消费旧接口，anti-corruption layer 把旧模型隔离在边界，避免污染新领域。新旧状态只设一个 source of truth，并定义同步期结束条件。

Codemod 处理机械迁移，feature flag/灰度控制流量，每阶段都有回滚。监控错误、性能、业务结果和迁移比例，而不只统计代码行。

重写适合原系统无法安全演进且边界可重建的少数场景；大多数长期系统采用渐进改造能降低双系统和需求停滞风险。
