# process 与应用生命周期

`process.argv` 保存命令行参数，`process.env` 的值是字符串或缺失，`cwd()` 返回当前工作目录，`exitCode` 设置自然退出时的状态码。配置层必须显式解析布尔值和数字，字符串 `'false'` 仍是真值。

## 退出事件

`beforeExit` 在事件循环将空时触发，并可安排更多异步工作；`exit` 发生在即将退出时，只能做同步收尾。SIGINT 常来自终端中断，SIGTERM 常用于进程管理器请求终止。

优雅退出流程是：收到信号后只执行一次；停止接收新请求；让负载均衡摘除实例；等待在途任务；关闭数据库、队列和日志；超过总期限后强制结束。设置 `exitCode` 并让事件循环自然排空，可减少 stdout 或文件写入丢失；直接 `process.exit()` 可能截断异步输出。

stdin/stdout/stderr 是标准流，连接终端时可能是 TTY，重定向时则是管道或文件。日志写 stderr、机器可消费结果写 stdout 有助于 CLI 组合。

退出码 0 表示成功，非 0 表示失败类别；让父进程、CI 和编排系统依此重试或报警。
