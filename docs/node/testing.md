# Node.js 测试与可测试性

单元测试隔离纯逻辑，集成测试连接数据库/文件/HTTP 等真实边界，端到端测试从外部调用完整服务。关键协议更适合集成测试，纯转换更适合单元测试。

Node Test Runner 提供 test/suite、生命周期 hook、mock、并发和覆盖率等能力，具体 API 随 Node 版本演进，应以项目锁定版本文档为准。

## 隔离外部资源

- timer 使用可控时钟，并验证微任务和取消。
- HTTP 服务监听端口 0，读取系统分配端口。
- 文件测试为每个用例创建独立临时目录并最终清理。
- 子进程测试设置超时，收集退出码和 stderr。

把时钟、网络客户端和文件接口作为依赖传入，比全局 monkey patch 更容易隔离且不受模块加载顺序影响。并行测试不得共享固定端口、数据库记录、cwd 或 process.env 可变状态。

flaky test 常源于未等待关闭、残留 timer/socket、竞态和依赖真实时间。覆盖率高只表示路径被执行，仍需对结果、副作用和失败模式做有效断言。
