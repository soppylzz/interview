# Core Web Vitals 与常见指标

| 指标 | 含义 |
| --- | --- |
| TTFB | 导航开始到首字节响应 |
| FCP | 首个 DOM 文本/图片等内容绘制 |
| LCP | 视口内最大内容元素的渲染时间 |
| INP | 页面生命周期内交互响应延迟的代表值 |
| CLS | 非预期布局位移的累积体验 |

LCP 候选会随更大元素出现而变化，用户交互、页面隐藏等时机会结束候选更新。可把 LCP 分解为 TTFB、资源加载延迟、资源加载时间和元素渲染延迟，从而区分服务端、发现优先级、下载和主线程问题。

一次交互包含输入等待、事件处理和浏览器呈现下一帧的延迟。INP 因此不只测 handler 执行。TBT 在实验室统计 FCP 到可交互窗口内 Long Task 的阻塞部分，可辅助预测主线程问题，但不能替代真实用户交互的 INP。

CLS 以 layout shift 的影响范围和移动距离计分，并按 session window 聚合；紧随某些用户输入发生的位移可能不计入。图片、广告和字体仍应预留空间。

FP/FCP、DOMContentLoaded、load 分别描述不同生命周期事件，都不等同于业务可用或可交互。阈值应依据 Core Web Vitals 当前标准，以移动和桌面真实访问的第 75 百分位评估，并保留页面类型切片。
