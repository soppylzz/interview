# 第三方脚本

统计、广告、客服和实验 SDK 会增加 DNS/连接、传输、解析执行、Long Task 和数据请求。`async/defer` 只改变加载和执行时机，不能消除执行成本。

## 控制策略

1. 建立第三方清单、负责人、用途和预算。
2. Consent 后或真正需要时加载，低价值能力延后到交互/空闲。
3. 为网络设置超时，API 调用有失败回退，避免阻塞核心流程。
4. 用 CSP、iframe 或 Worker 按能力隔离；iframe 隔离 DOM/样式但仍消耗同设备资源，Worker 隔离主线程但不能运行依赖 DOM 的 SDK。

服务端转发能减少客户端连接或隐藏服务端凭据，却增加后端延迟与合规责任。自托管可控制缓存和可用性，但必须负责更新、安全修复、许可证和数据处理，不能复制后永久不升级。

用 Resource Timing/Network 统计传输和调用，用 Performance trace/Long Tasks 归因主线程，并按未同意、未使用和不同设备人群比较实际成本。
