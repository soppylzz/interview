# Web 安全模型

asset 是要保护的数据/能力，threat 是潜在危害，vulnerability 是可被利用的缺陷，risk 综合可能性与影响。安全设计从数据流和 trust boundary 开始，而不是从攻击名词开始。

浏览器以 origin/site、安全上下文、进程隔离和权限为基础建立边界。认证确认身份，授权判断操作，输入校验保证数据符合业务规则，输出编码防止数据在特定解释上下文变成代码。

客户端由用户控制，前端校验和隐藏按钮只能改善体验，服务端必须重新校验与授权。纵深防御让一层失效时仍有 SameSite、CSP、最小权限、审计等其他控制。

最小权限包括最小 token scope、最少第三方脚本、严格 iframe/Permissions Policy，以及仅向前端暴露必要数据。
