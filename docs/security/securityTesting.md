# 安全测试与事件响应

Threat modeling 先列资产、数据流、边界和 abuse case，再选择测试。SAST 查源码模式，DAST 从运行页面测试，SCA 分析依赖；三者覆盖面不同且都有误报/漏报。

浏览器 DevTools 可检查 CSP/Cookie/请求，代理工具可修改和重放流量。自动扫描不能理解复杂授权、业务状态和组合攻击，关键流程需要人工验证。

漏洞按可利用性、影响和暴露范围分级，修复根因后增加回归测试。安全事件需准备禁用功能、回滚版本、撤销 token/session、轮换秘密和通知路径。

复盘记录时间线、控制为何失效和可验证行动项，避免只归责个人。测试只在明确授权的环境和范围内执行。
