# 常见函数式与手写模式

debounce 在连续触发停止一段时间后执行，可支持 leading/trailing/maxWait；throttle 限制时间窗口内频率。两者都要处理参数、this、取消和 flush。

curry 把多参数函数逐步收集参数，partial 预填部分参数；compose 从右向左组合，pipe 从左向右。抽象应服务于数据流可读性，而不是追求形式。

memoize 需要稳定 cache key、容量和失效策略；对象参数可用 WeakMap 分层，但多参数与原始值仍需设计。无界缓存会成为泄漏。

发布订阅通过中介按事件名分发，观察者通常让 subject 直接维护 observer。并发池控制同时运行数量；retry 要限制次数、仅处理可重试错误、使用退避抖动并考虑幂等性。

手写题先声明语义边界，再实现和测试空输入、异常、取消、重复调用及资源清理，不能只覆盖快乐路径。
