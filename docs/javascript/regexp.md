# 正则表达式

正则由字符类、量词、分组、alternation、边界和 lookaround 组合。捕获组用于提取，`(?:...)` 只分组不捕获，命名组提高可读性。

量词默认贪婪，后加 `?` 变懒惰，但“懒惰”不等于一定更快。`g` 与 `y` 会更新 RegExp.lastIndex，复用实例执行 test/exec 时结果可能受上次调用影响。

复杂嵌套量词和重叠分支可能产生灾难性回溯，攻击者可构造长输入导致 ReDoS。限制输入、简化模式、避免歧义，并在最坏数据上测试。

正则适合局部文本模式，不适合完整解析递归语法、HTML 或 URL；这些应使用对应 parser/API。
