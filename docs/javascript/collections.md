# Map、Set 与弱引用集合

Map 可使用任意值作 key，保留插入顺序，提供 size 和明确的增删查 API；Object 更适合有固定字段的记录，还会涉及原型和属性描述符。性能结论应基于真实工作负载，不能只说 Map 永远更快。

Set 按 SameValueZero 比较，NaN 可等于自身，正负零视为相同。它适合成员关系和去重，但对象仍按身份比较。

WeakMap/WeakSet 的 key 必须是可垃圾回收的对象或相应可用符号，弱引用不会单独阻止 key 回收。为避免暴露 GC 时机，它们不可枚举，适合对象元数据、私有状态和缓存。

WeakRef/FinalizationRegistry 的回调时间不确定，甚至可能不执行，不能用于关键资源释放或业务逻辑；资源应显式关闭。
