# 函数与参数

函数声明通常可在声明前调用；函数表达式遵循变量初始化时机；箭头函数语法简洁但没有自己的 this，也不能 new。

参数按值传递。默认参数在独立参数作用域中从左到右求值，可引用前面的参数。rest parameter 是真正数组；`arguments` 是 array-like，在非严格简单参数场景还可能与参数别名联动，应优先使用 rest。

函数也是对象，`name` 用于诊断，`length` 通常表示第一个默认/rest 参数之前的形参数量。高阶函数接收或返回函数；纯函数在相同输入下产生相同输出且不修改外部可观察状态。

递归深度受调用栈限制。规范定义的尾调用优化并未获得所有主流引擎一致支持，生产代码不能依赖它消除栈增长。
