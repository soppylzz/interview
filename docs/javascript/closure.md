# 闭包

闭包是函数与其词法环境引用的组合。函数创建时即可形成闭包，外层函数返回后，只要内层函数仍可达，被捕获的 binding 就仍可访问。

闭包捕获 binding，而不是创建时的值快照，所以多个函数可以观察同一变量后续变化。`var` 循环只有一个函数作用域 binding；`let` 的循环语义会为每次迭代建立绑定。

常见用途包括私有状态、工厂函数、memoize、debounce 和模块状态。闭包本身不是泄漏；只有不再需要的数据仍被可达的闭包、监听器或 timer 引用时才是泄漏。

降低风险的方法是缩小捕获对象、及时解除订阅和 timer、让缓存有上限，并用 heap snapshot 的 retaining path 找到实际引用链。
