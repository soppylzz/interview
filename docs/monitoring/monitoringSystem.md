# 前端监控体系

errors 描述失败，logs 保存离散上下文，metrics 聚合趋势，traces 串联一次请求，replay 重建用户操作。业务埋点回答产品行为，可观测性回答系统为何异常，两者可共享 session/release 但目标不同。

完整链路是采集、内存缓冲、可靠上报、清洗、聚合、存储、告警、定位和恢复。每条事件至少关联 release、environment、page/route、session、设备和时间。

RUM 反映真实设备与网络；实验室数据环境可控，适合复现。监控必须设置采样、payload 上限、脱敏和保留期，否则会反过来损害性能、成本和隐私。

先定义可行动问题和 owner，再采数据；无法用于决策的无限日志不是可观测性。
