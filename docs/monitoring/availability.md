# 白屏、崩溃与可用性

白屏应按业务关键内容在期限内未出现定义，而非 body 无节点。可结合关键元素、可见面积、DOM 文本、像素采样和应用心跳，避免骨架屏/弹窗造成误判。

ChunkLoadError 常来自 HTML 与 hash 资源发布不一致、缓存旧入口或网络失败。记录请求 URL、release、Service Worker 和资源状态，重试/刷新前防止循环。

Long Task、交互无响应、内存持续增长可提示卡死，但进程被系统杀死时页面可能无法最终上报。用下次启动标记、服务端会话缺失和 RUM 聚合补充判断。

自动刷新可能丢数据并制造循环，应先保存状态、限制次数、提供手动恢复和静态 fallback。
