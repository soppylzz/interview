# Dialog、Popover 与交互元素

`dialog.showModal()` 创建模态对话框和 top layer，浏览器处理背景 inert、Esc cancel 等基础行为；`show()` 是非模态。关闭后应把焦点恢复到合理触发点，并提供清晰标题与关闭操作。

popover 提供声明式显示、top layer、轻量关闭等行为，适合菜单、提示等非模态浮层。不同交互类型仍需正确焦点和键盘设计。

details/summary 提供原生可展开区域，适合 FAQ 和附加信息。原生元素减少自造组件遗漏，但样式、兼容和产品行为仍需测试。

自造弹窗常遗漏焦点进入/恢复、Tab 范围、Esc、背景交互、滚动锁和可访问名称，应优先复用平台能力。
