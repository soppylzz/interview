# HTML 可访问性基础

辅助技术通过语义和可访问性树理解元素的 name、role、state/value。优先使用原生 button、input、select 等，因为它们自带键盘、焦点、状态和平台语义。

可访问名称可来自可见 label、元素内容、alt、aria-labelledby 等；描述可用 aria-describedby。图片 alt 描述用途，装饰图用空 alt，不能把文件名当说明。

自然 DOM 顺序应对应阅读和键盘顺序。`tabindex="0"` 加入自然顺序，`-1` 允许程序聚焦但不在 Tab 顺序；正数会制造难维护的顺序，通常避免。

焦点必须可见。弹窗、路由和异步错误需要主动管理焦点，但不能在用户输入时随意抢焦点。WCAG 的四原则是可感知、可操作、可理解、健壮；自动工具只能发现其中一部分问题。
