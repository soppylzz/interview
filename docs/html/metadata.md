# Metadata 与 SEO

title 是页面和搜索结果的重要名称；meta description 提供摘要候选；charset 应尽早声明；viewport 让移动布局按设备宽度工作。

canonical 表示首选重复内容 URL，robots 控制抓取/索引提示，hreflang 描述语言地区版本。Open Graph 等元数据影响社交分享，structured data 用标准词汇描述实体，不能保证展示富结果。

SEO 还取决于可抓取链接、状态码、内容质量、性能、移动体验和一致 URL。只加 meta 标签不足以解决索引问题。

CSR 内容是否可见取决于 crawler 执行能力和资源条件；SSR/SSG 可更早提供 HTML，但仍需正确语义、canonical 和错误状态。
