# Network 进阶索引

> 进阶部分用于理解协议在丢包、拥塞、地址转换和复杂网络环境中的行为。前端面试通常要求理解目的和取舍，不要求背诵全部报文字段。

## 主题

1. [TCP 进阶](./tcpAdvanced.md)
2. [DNS 进阶](./dnsAdvanced.md)
3. [QUIC 进阶](./quic.md)
4. [WebRTC 网络基础](./webRtc.md)

## 学习重点

- TCP 如何根据接收方能力和网络拥塞调整发送速度。
- MTU、MSS、分片与丢包之间的关系。
- DNS 的缓存、一致性、隐私和完整性问题。
- QUIC 如何在 UDP 之上实现可靠传输、独立流和连接迁移。
- WebRTC 如何借助 ICE、STUN、TURN 穿越 NAT。

## 不必死记

- TCP 拥塞窗口的每个实现细节。
- DNS 和 QUIC 报文的全部二进制字段。
- 不同浏览器 WebRTC 实现中的私有策略。

面试回答应先讲协议要解决的问题，再讲机制和代价。
